The APK is labeled **Cyclades Preview**. It uses the same test signer as Preview 16.1 and can update that installation. It installs separately from the original Cyclades app; use export/import to transfer a campaign from the original. Export a backup before installing an update. No private signing keys or credentials are included.

This update adds consistent illustrated actions with simple utility controls, bright dark-mode text and colored building counters, manual Continue after battle rounds, brief named announcements, direct Triton map selection with glowing buildings, smarter piece placement and resource badges, a pinned settings X, softer tile seams, and a new skippable intro and richer battle motion. The existing territory geometry, connections and gameplay are preserved.

All 29 production-browser checks pass. Source-provided v16 features, tall/wide layout, interaction, integration and full core/Maelstrom campaigns also pass. Two inherited rules/test-harness discrepancies remain documented in CHANGES.md. Android signatures and alignment verify; physical Android behavior and device performance have not been tested.
