# Cyclades 16.1 downloads

Open either file below and click **Download raw file** in GitHub.

- [Android test app](Cyclades-v16.1-preview.apk)
- [Complete source ZIP](Cyclades-v16.1-full-source.zip)

The APK installs separately as **Cyclades Preview** and uses a test signing key. It does not replace your existing app. Export/import a campaign to transfer it. The build signatures and alignment verify; physical Android device testing has not been performed.

The source includes the recovered game assets, original Android wrapper and tests, the improvements, and reproducible build instructions. Signing keys and credentials are excluded. Sixteen browser tests pass; inherited capture-bonus rules and legacy harness discrepancies are documented in docs/IMPROVEMENTS.md inside the source archive.
